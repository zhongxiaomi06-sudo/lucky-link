[打开本地预览](http://127.0.0.1:5114/) · [当前验证与证据](./TESTING.md) · [产品规则](./PRODUCT.md) · [交付边界](./RELEASE.md)。

项目为 Ice Blue Lucky Drop：完整蓝白手机链 Hook → 写实托盘内点击投放、同款三碰消除 → 冰蓝完整挂件 3D 揭晓 → 每次通关抽一张模拟优惠券。默认入口使用既有 `tabletop.js` 底座与 `collection-ui.js`，不是已停止作为默认入口的 V33 四身份实验。

每局 60 件初始配饰、5 个匹配身份、60 秒；十一件冰蓝模块按顺序解锁，目标从 1500 分逐关增加 100 分至 2500 分。集齐后可继续挑战抽券；券额为 ¥5／¥10／¥15。已解锁模块和券记录保留在本浏览器。商品链接仍为模拟占位，不具备真实兑换、购买或履约能力。

V42 接入玻璃、珍珠、树脂、金属四类质量、回弹、摩擦与旋转响应，按实际接触强度播放声音并在碰撞点给出短反馈，不再让整盘随每次碰撞抖动。首件“冰晶星愿”改为封闭双面切割星星、梨形水滴与连接五金；其余十款仍保留原程序模型，没有宣称全部精修或 Meshy 精确复刻。玩法、60 件数量和通关奖励规则未改。

[物理测量](./evidence/material-physics-v42/report.json)中默认盘最大穿插为 2.734 单位，落稳后无持续旋转或接触音；两个高阶密集样本从 16.322／12.528 降至 12.730／6.814，仍超过 4 单位验收线。V44 的 30 个测试文件／227 项测试、生产构建及定向 lint 已通过，Three.js 573.64 kB 构建警告仍是交付阻断。实际双浏览器各两轮流程审计结果以 [TESTING](./TESTING.md) 为准，不沿用 V42 结果充当本轮通过。[V44 实际首关音频报告](./evidence/reveal-studio-v44-audio/actual-flow/report.json)已通过，无页面异常，但不代替真实 iPhone、物理扬声器或最终审美验收。

V41 的小屏／横屏布局、计时、声音、揭晓生命周期、手动 3D 角度及存档清洗修复继续保留；历史结果见 [TESTING](./TESTING.md)，不以旧版本通过数代替当前验证。

## 本地运行

在仓库根运行：

```sh
pnpm --filter @eazo/lucky-link dev
pnpm --filter @eazo/lucky-link build
pnpm exec vitest run apps/lucky-link/src
```

应用包：`@eazo/lucky-link`；默认端口：`5114`。默认首页可直接进入游戏；`?studio=1` 保留既有 DIY 工作台，`?view=3d` 保留历史 3D 入口，不是本轮扩展目标。
