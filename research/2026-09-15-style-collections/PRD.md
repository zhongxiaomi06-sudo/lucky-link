# 六系列素材增量｜建议稿，未批准开发规格

## 0. 参考比较门禁

四家直接手机配件参考和一家首饰替代参考见[矩阵](./competitor-analysis.md)。当前证据是官方商品文本／图注，不是Instagram原图或实玩竞品。差异化假设：相同近景中，增加形状、表面及大小层次，让选珠更有辨识度；**竞争力与沉浸提升未证明**。

状态：D0研究；V16近景方向另有Owner批准，六系列独立资产／新库数量／解锁配置未签收。技术与移动预算未明确到新增资源，因此本文件不自称可直接排期的最终PRD。不改既有Spec Kit feature指针或已批准规则。

## 1. 问题与用户

钟笑咪指出当前链条不好看、占比应更大，并要求风格多样化。现有默认2D游戏已可取放、配对、收藏和导出真实作品；当前素材限制不应通过堆积更多同形换色或大背景掩盖。目标是想自由混搭手机链的轻创作用户，不面向真实首饰制造、材质鉴定或付费实物兑换。

| 层级 | 边界 |
| --- | --- |

| 本轮范围 | 核对V16批准、筛选六系列、来源与风险记录；没有开发或新媒体 |
| 下一步建议 | 一张统一系列素材视觉板；确认后把具体资产清单、数据兼容和预算写回现有Spec Kit再实施 |
| 技术上限 | 继续2D，不添加运行外部API／账户；保留3–14件、44px命中、原收藏及分享契约；新增资源包体／内存／延迟预算尚缺，未批准前不接入 |
| 延后 | 新素材总数、初始与锁定分配、按风格收藏筛选、首页单独改图、线上更新；各自确认后才纳入 |
| 禁止 | 偷改草稿／拥有关系，虚假点赞／实物承诺，品牌整串或联名角色照搬，绕过登录抓取，个人Note外传，假称2D为真实360° |

## 3. 页面与状态契约（提案）

不增加六个主题房间或前置教程。继续在原珠盒选择素材，收藏／游戏／完成页读取同一份素材定义。

| 状态 | 要求 |
| --- | --- |
| 正常／退出 | 保持原点击或拖放及撤销；离开选材不改变当前串 |
| 空串／空筛选 | 空串可继续加珠；筛选无可用项给短说明和返回全部，不自动填示范作品 |
| 加载／错误 | 未就绪珠子不可假装可用；有重试或使用已就绪内容的路，不提交不存在的素材 |
| 离线 | 已缓存／已就绪的本地材料可以使用；缺图明确失败，不伪造拥有关系 |
| 锁定／配对 | 用已有V14规则，不因切系列绕过锁；Use bead仍由玩家亲自放入 |
| 权限／存储 | 无新增权限；分享取消留在卡片、存储失败沿用Session only |
| 减少动态／低性能 | 不做持续转动或大泛光；材料区别靠静态轮廓和光泽也应成立 |
| 短屏／横屏／键盘 | 完整链与动作不互相遮挡；可滚动选材、44px目标、焦点与16px输入保持 |

## 4. 待确认的需求

下列共同字段：Owner为钟笑咪；状态均为pending；不新增权限／远程埋点，验证使用隔离本地数据，不读Owner存档。数据来源为原创素材和项目材料定义，品牌网页只作为参考链接。

### SC-R1｜有区别的系列，不是六套换色

- 前提／输入：V16近景已批准；选择一个系列和其中已拥有的素材。
- 正常：展示具有区别的主珠／配珠轮廓及材质；拿起后走原取放事务。
- 异常：素材未批准／未就绪／锁定时不得直接加入；错误仍能返回。
- 状态变化／输出：浏览不改composition；有效放下才新增一个实际ID，制作／完成／作品卡一致。
- 数据：稳定materialId、建议seriesId、shape、finish、displaySize、assetVersion；大小单位CSS px，候选形状数量未定。旧ID不改名、不删除。
- 无障碍：简短名称可读；键盘／点击也能选择，不能只靠颜色；命中不小于44px。
- 上限／验收：继续14件上限；每个系列需可辨识的主珠与配珠，不以相同轮廓换色宣称新模型。Given已拥有一颗，When浏览另一系列，Then原串及所有权不变；When合法串入，Then仅增加所选一颗。

### SC-R2｜放大作品但不牺牲取放

- 前提／输入：按已批准V16构图，测试3／8／14件和不同宽窄珠混搭。
- 正常：手机只保留连接语境，闭环完整突出，珠盒位于下部；粗主珠、细配珠和五金有层次。
- 异常：短屏／横屏不得靠裁掉作品或缩小命中伪装成功；增加可用的局部重排／布局适配，不变更实际顺序。
- 状态变化／输出：布局只影响屏幕坐标与显示尺寸，不改素材ID、数量、顺序或拥有关系。
- 数据／单位：同一布局坐标给Canvas和输入命中使用；CSS px，构图依据V16批准PNG及其哈希。
- 无障碍／上限：44px、触控无Hover、键盘替代、减少动态；不新增全景相机或真实3D承诺。
- 验收：Given满14件，When进入完成／作品卡／返回编辑，Then同一实际串保持，按钮不遮挡关键区域。技术结果不能替代Owner审美签收。

### SC-R3｜旧作品、收藏、声音不被素材升级破坏

- 前提／输入：包含旧ID、重复珠、未满串和Note的隔离测试档。
- 正常：继续读取旧档；新图可以升级但不偷偷改配方，新增素材获取资格需独立批准配置。
- 异常：未知ID／加载失败／坏存储遵循明确降级，不通过清空收藏修复；保留可恢复原始记录。
- 状态变化／输出：浏览不持久化作品变化；保存／分享仍只包含实际作品与用户Note，无品牌／水印。
- 数据／单位：旧collection key、materialId与Unicode Note上限保留；新增资产版本独立，不覆盖原图或原哈希。
- 无障碍／上限：保留静音持久化、后台停音和原分享失败替代路径；没有新增API／跨设备同步。
- 验收：Given旧作品，When升级后加载并导出，Then逐ID／顺序／数量一致；When系统分享取消，Then不自动上传或下载。

## 5. 验证、预算与收敛

| 指标 | 定义／样本／目标 | 失败动作 |
| --- | --- | --- |
| 真正风格差异 | 六系列候选中具备不同轮廓与表面语言的数量／六；目标全部，按同尺寸静态素材板人工逐项核对 | 重做相似系列，不加更多换色数量 |
| 作品一致 | 隔离3／8／14件样本在制作、完成、导出中的正确ID顺序次数／全部检查次数；目标全部 | 停止接入并保留旧版本 |
| 未遮挡可操作 | 320×568、390×844及短横屏等原有矩阵中实际可触达目标／全部目标；目标全部且至少44px | 修复布局，不能裁掉目标或降命中门槛 |
| 沉浸／审美 | Owner对同尺寸新旧真实截图及一次操作片段的明确反馈；未收集，不以算法代签 | 收集一个具体问题后修正 |
| 新资源开销 | 新增压缩字节数、解码内存、交互延迟和帧耗时；目前没有新素材，也未定发布阈值 | 预算在受控开发前冻结；不承诺60fps |

不安装新框架；不加入按系列自动修改草稿的捷径。候选素材图、核心图集、移动性能预算和新素材解锁分配批准前，本建议停在设计阶段。之后运行现有单元／两浏览器矩阵、分享与声音回归，以及目标正式iPhone两轮。当前没有新测试结果；旧V15证据仅是原版本基线。
