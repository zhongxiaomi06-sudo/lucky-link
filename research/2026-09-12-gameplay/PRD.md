# 串珠手作小店 · PRD 草案

2026-09-12 · **未批准，不是实施指令**。Owner：钟笑咪。来源及置信见 [账本](./source-ledger.md)；现状以项目七文档为准。

## 0. 竞品门禁

直接操作类比较：Bead Art: Coloring Games、Bead Art 3D、MeltyHeart；替代：Perler、Unpacking。均有第一方结构依据，未实玩。[统一矩阵](./competitor-analysis.md)。

比较任务：一个手机用户能否顺手做成一条属于自己的手机链，并愿意看/保存实际成品。差异化是假设：商品摄影般的材质、不同制作任务、可感知收尾可以改善 V12 的“搭完就评分”。没有竞争优势或留存结论。

方向讨论：PASS WITH CONDITIONS。实施：BLOCKED，须批准新构图、规则关系、素材/数据方案和验证范围。失败阈值与继续/停止动作见第 6 节。

## 1. 用户问题与唯一方案

钟笑咪明确指出手机表现不精细、玩法不沉浸。V12 已有取放/撤销/关卡/评分/声音，所以重复添加这些名字不是升级。

推荐的循环：**小委托 → 近景选放 → 珠子穿线靠拢 → 一次收线合扣 → 同串挂手机 → 成品图/继续创作**。真实的决策集中在挑选与排列，动画承担工序，不要求精细针线操作。

## 2. 四层边界

| 层 | 范围 |
|---|---|
| 体验上限 | 让人通过低压力短时手作，完成可欣赏、可定制的闭环手机链；不是经营/抽卡/社交产品 |
| 首个验证切片 | 一台精细无品牌手机、既有代表素材的精修、一个新引导委托＋自由 DIY、单次放置反馈、轻收尾和同串成品。先验证完整流程，再批量铺关卡 |
| 后续候选 | 五委托的差异化任务、根据可解性表补充缺失款、无水印成品保存；均需要对应的规则/素材/数据批准，不是本轮已实现 |
| 禁止/拒绝 | 商业图片拆件、未授权配乐、假实时 3D/360°、复制受保护关卡角色、精细瞄孔才能成功、强制广告/体力/倒计时、自动发送备注或下单 |

不清空旧 24+5 款、五关进度、草稿或电商配置。新评分与旧评分如不兼容，须明确版本与迁移，不能把“保留五关”当成已经解决这个问题。

## 3. 五个委托怎样不同（待确认配置）

沿用既有五个主题与顺序，下面不是新增五个模式入口。每关最多提示一项当前动作、两条短要求；不用常驻文字面板。

| 主题 | 主操作变化 | 自由度/正确性边界 |
|---|---|---|
| Ocean wish | 看三珠节奏，补上下一颗；学会取/放/撤销 | 可退出引导直接 DIY；不要求唯一 SKU 或完美像素位置 |
| Rose letter | 在独立样例里找到缺口并补珠 | 样例不覆盖旧草稿；可重开/退出；已有模板珠若保留到成品，必须如实计入清单 |
| Garden picnic | 从有限主题色建议中挑主吊坠，再搭配其他珠 | 色盘是建议，不靠奖励锁死通关；至少两种视觉不同的合法解 |
| Moonlight walk | 调整以连接扣为锚点的两侧轻重与色彩 | 平衡不等于镜像，允许不对称；判定必须有可解释例子 |
| Color story | 两条简短风格要求下完整自由创作 | 不给唯一排列，消费/稀有度不计分；Free DIY 无考核 |

先制作“主题×色族×形状×可用库存×奖励依赖”的可解性表。不能先写固定题再强迫用户购买/解锁材料。若某类吊坠缺失，只补该缺口；不能把变色当新模型数量宣传。

## 4. 页面与状态

| 页面/阶段 | 入口与正常输出 | 空/加载/错误/离线/权限 | 动态/性能/退出 |
|---|---|---|---|
| 工作台 | 直接见一串可操作材料、右盒、短委托和壳色色样；取放区为主视觉 | 空串只提示一个宽容落点；分层素材就绪才开放对应拾取；失败可重试且不换成假成品；离线已有本地资源可继续，首次未缓存需提示重试 | 至少44px按钮；短屏减少盒内可见行；减少动态不播循环光；返回不丢草稿 |
| 收尾 | 3–14 件后点 Finish 或等效拖线；清楚收紧/合扣反馈 | 不足数量提示；取消/失焦不修改组成；无额外权限，不等待网络或音频 | 动画可跳过；无长按/限时，重看结果不强制重演；Edit 回原串 |
| 成品 | 全貌、近景、手机搭配读取同一个作品；手机和锚点精细可读 | 无成品不能伪造示例；保存/存储失败保留会话，明确失败；分享不可用时仅本地保存入口，不强迫权限 | 无品牌/水印的保存图；低性能静态近看；不宣称背面360°；Edit/下一委托保留可见入口 |
| 规则/清单 | 主动打开现有语义 dialog | 键盘/存储失败/非法链接沿用原合同；无电商 URL 不显示假商品按钮 | 固定可见关闭入口、焦点返回；无横溢，输入≥16px；作品在后台不变 |

## 5. 核心要求合同（全部 Pending）

共同字段：数据来源为现有合法素材 catalog 与 composition；数量单位件、坐标 CSS px、时间 ms。仅本地内存/浏览器存储；不发用户作品/备注到分析服务。测试事件在隔离会话本地采集。Owner 均为钟笑咪，实现/测量责任为项目维护者。

### R1：一颗珠子，一次放置意图

- 前置/输入：工作台可用，点取＋点位置，或一次拖放；来源包括库存和暂存盒。
- 正常：持珠浮在指尖上方→展示插入位置→有效释放提交一次→播放短穿线/碰齐反馈。无需点中孔，原来的插入/重排/退盒仍可用。
- 异常：无效释放、取消、多指、失焦不提交；满串保留来源；库存竖滑不能拿珠。
- 状态/输出：同一原子事务更新 composition/box/history；预览和动画不保存。字段沿用 materialId/ordered IDs，不能以屏幕位置当唯一顺序。
- 无障碍/限制：点选与拖放等效、完整顺序面板可精确编辑；3–14 件，44px 以上目标；静音下状态仍可见。
- 记录：pickup/preview/commit/cancel/undo 时间及动作类型，本地测试不含私人备注。
- 验收：Given 手持新珠且落点旁已有珠，When 点击/释放，Then 仅加一件、不进旧珠菜单；撤销恢复完整串和盒。动画跳过或音频失败不改变结果。

### R2：不同制作任务，而非换个标题

- 前置/输入：用户主动进入新引导委托或既有自由模式；读取版本化任务配置。
- 正常：一项当前动作和最多两条目标，放置后即时给局部提示；后三关至少两个明显不同排列可完成。
- 异常：配置缺 SKU/不可解则不启用新任务，不在运行时无限重试；退出教学可进 DIY；不覆盖已保存旧草稿。
- 状态/输出：候选字段 taskKind、rulesVersion、allowedHints、templateIds、completionState；具体 schema 和奖励映射未批准。
- 无障碍/限制：不要只用色彩表达正确性；提示可展开阅读；无时间/购买要求；自由模式无教学正确答案。
- 记录：首个有效动作、要求打开次数、误放/重排、退出原因；仅经同意的本地测试。
- 验收：Given 当关实际已解锁库存，When 使用至少两套合法方案，Then 均能按明文规则完成；完成/重复提交不重复发奖。**新硬条件与旧70分关系未澄清前，不进入开发。**

### R3：轻收尾，不把手工变成操作考试

- 前置/输入：合法3–14件；点击 Finish 或可选拖线，二者等效。
- 正常：一次收尾反馈让绳孔/珠序/扣合关系清楚，再进入同一作品展示；默认目标≤1.2s，立即可跳过。
- 异常：连续点击幂等；音频、失焦和动画取消不多发奖、不加珠；重开结果不重演必经动画。
- 状态/输出：UI compose→closing→showcase；composition不变，奖励仍单独事务处理；无新权限。
- 无障碍/限制：单点击可完成，减少动态直接展示合扣后的状态；不长按、不要求双指拉线、无计时。
- 记录：finish/skip/showcase 时点与作品标识；不采用户身份。
- 验收：Given 同一作品，When 分别点击完成、拖线完成、跳过动画，Then 数量顺序绳色及奖励完全一致。

### R4：精细手机与实际成品同源

- 前置/输入：作品有效、所需独立美术资源就绪；切换 Detail/On phone 或 Edit。
- 正常：手机后盖/壳边/镜片/金属件光向统一；壳底锚点→扣→线→珠孔连续；图像边缘无旧灰格/色键残留。仅原作品重新取景，不偷偷补珠。
- 异常：缺图给重试，不替换为固定宣传串；小屏重新排布，不把按钮叠在珠子上；导出失败不报成功。
- 状态/输出：同一 composition + cordColor + phoneVariant + renderVersion；后两个是候选字段，未写存档。清单以实际选材为准。
- 无障碍/限制：切换提供语义按钮，完整顺序可读；成品保存无品牌/水印；无相机权限、不把2D变形称360°。
- 记录：展示/导出 composition 摘要与渲染版本，仅本地测试；无私人备注或外链访问统计。
- 验收：Given 3件和14件作品，When 制作、完成、近看、挂手机、返回、刷新和生成清单，Then ID/顺序/数量/色彩一致；Owner 基于实际图确认手机与锚点合理，不能由单测替代。

### R5：声音是动作反馈，不是满屏叮当

- 前置/输入：首次有效手势后、非静音、页面可见；实际动作事件触发声音。
- 正常：木盒拿取、玻璃轻碰、软质珠落下、金属合扣可区分；保持低强度主题音乐与一次性奖励声。
- 异常：失败/取消不播成功音，重复提交不重播首次奖励；音频不可用仍能完成；后台暂停，恢复不得积压补播。
- 状态/输出：沿用静音键与本地持久化，原创合成/合规新录音；不调用麦克风，不下载品牌音乐。
- 无障碍/限制：关键反馈有视觉对应；声部预算沿用现有24上限；不要每个预览帧发声。
- 记录：动作/SFX配对、静音与后台事件，本地声轨；录音素材若新增另记来源/版本/哈希。
- 验收：Given 静音和音频失败两种状态，When 完整制作/完成，Then 流程可用；有声时真机试听无突兀叠音。事件存在不等于听感通过。

## 6. 验证、指标和失败动作

以下全是**待批准的测试目标**，不是研究结果。第一轮用同一批5名目标体验者对照 V12 与新切片；版本顺序交错，记录小样本偏差，不推断留存。

| 指标 | 定义/分母/窗口 | 目标/失败阈值 | 工具与失败动作 |
|---|---|---|---|
| 主题可理解 | 5人各看3秒，能说出“做手机链”和下一步人数/5 | ≥4/5；不足即失败 | 观察记录；修改构图，不加教程墙 |
| 首次闭环 | 5人从首次进入到3件带手机展示的独立完成次数/5，计时45s | ≥4/5在45s内；不足失败 | 录像/时点；先减少操作环节，不强加长收尾 |
| 取放正确 | 每人20次有明确意图的添加/插入/取消，共100次；误提交数/100 | 误提交≤5%，丢失/重复0；任一丢失即失败 | 测试日志+录像；优先修输入，不靠动画掩盖 |
| 可见延迟 | 冷首触单列，随后每设备100次事件到可见反馈；报告p95 | p95≤100ms；超过失败 | 浏览器时点仅近似，真机录像交叉核对；停环境动效/预热资源后重测 |
| 同串一致 | 合法3/8/14件、重复款、奖励款与取消回退fixture，各展示和导出字段相等数/全部断言 | 100%；任一不一致阻止交付 | 单元+Chromium/WebKit；修单一数据源 |
| 任务可解 | 五委托/实际解锁库存的解法检查，后3关≥2个视觉不同方案 | 5/5可解且无奖励依赖死锁；否则失败 | 配置测试+实际全通；改题或按缺口补材 |
| 体验改善 | 同样材料下，5人指出是否更像“亲手串成”并给原因；偏好新版本人数/5 | ≥4/5且误触不退步；否则不推广 | 不将偏好当因果；若被认为拖沓，缩/取消收尾；不能只按加分过关 |

设备矩阵、包体/帧预算见 [技术边界](./open-source-framework-review.md)。两轮正式 iPhone、安全区、键盘、横屏/短屏、200%文字、静音/减少动态、音频/存储/图片失败都仍为必验。当前没有新测试结果。

## 7. 数据、权利与回退

- 草案新增数据仅为本地任务配置/瞬时工序/渲染元信息；判定版本、旧存档迁移和结果保存机制须批准后具体化。不要覆盖当前 `lucky-link.styling.v2` 或重置旧奖励。
- 核心离线指本地资源已可用后的流程，不承诺从未访问的设备断网也能加载。图片/声音失败有明确可恢复状态。
- 品牌图、截图、教程和 Apple 图纸仅研究；运行资源必须原创/许可明确并记录 DAM 版本。没有获得新商业素材权利；字体和程序声音沿用原账本，不把研究链接作为 license。
- 若保存失败保留会话与原草稿；清理只能由用户明确选择，不因升级自动删除数据。备注不进入外链/遥测。
- D2 采用独立试验入口或本地功能开关，不改线上默认；保留 V12 入口及原资源版本。回退关闭新入口，不删除新旧草稿，不用破坏性 git 命令。
- 不发布、不改访问权限。正式上线仍需明确授权；项目阶段没有因调研改变。
