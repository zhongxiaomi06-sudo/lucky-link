## 研究协作框架

采用现有 Codex 会话中的显式流程：范围冻结→发现→来源核验→统一比较→交叉反证→草案→Owner 审批。主线程承担摄影/产品/技术与来源复核；一个有界研究分工承担拼豆来源和反证复核。没有引入新的 Agent runtime，没有声称安装 LangGraph、CrewAI 或 DSPy。

框架版本/许可：现有会话工具由宿主提供，无本轮新增分发软件；精确服务 build 不可见。fallback 为本地来源表和人工阶段门禁。角色只是审阅责任，不等于所有角色都有独立 Agent 或独立验证。

## 建议的最小架构改动（仅草案）

- 继续使用一个 composition 作为顺序/数量真相；制作、收尾、手机展示、导出清单不能各自拼一串。
- `compose → closing → showcase` 是短暂 UI 阶段；动画不提交珠子、不发奖励。提交与首次领奖继续幂等。
- 独立绘制孔、绳穿过的前后关系和接触影。可预渲染材质，不声称实时 PBR/真实折射。
- 新任务配置只引用合法素材 ID/色族，不用 AI 打分或远端生成关卡。
- 新玩法存档/判定版本必须在批准后设计；保留旧数据，不能借重构清空作品或重发奖励。
- `prefers-reduced-motion`、静音和后台停帧保持；触觉震动只能为可选能力，不宣称所有 iPhone 浏览器支持。

## 待测的技术上限，不是承诺

| 指标 | 候选上限/验证方案 |
|---|---|
| 内容/存储 | 仍 3–14 件、24+5 个已知素材、60 件暂存、50 步撤销；新增样式须经缺口表/数据审批 |
| 外部请求 | 核心循环 0 个第三方 API/模型调用；无摄像头/麦克风/传感器权限；商家链接仅显式操作 |
| 资源 | 首次可玩新增传输预算 ≤2 MiB、默认总关键资源目标 ≤6 MiB；均是拟定预算，V12 未证明满足。超预算先压缩/延迟加载，不自动降画质或声称已优化 |
| 输入 | 持珠到可见反馈 p95 ≤100 ms；点选/拖放同结果；44px 以上语义入口；不以极小珠孔当命中区 |
| 动画 | 拟定 60Hz 设备拖放帧间隔 p95 ≤20ms；低性能改为按需绘制并关闭环境循环，高光不能妨碍取放。需真机测，失败不宣称 60fps |
| 支持范围 | 当前正式 iPhone/iOS 在 SELF_TEST 开始时重新核验；桌面 Chromium/WebKit；旧 iOS/iPad 不作保证。代表视口沿用 V12，不把仿真视口名当真实型号 |
| 收尾 | 初稿目标 ≤1.2s 自动反馈，立即可跳过；重开结果不重复播放。非计时考验，具体节奏待听感/真机测试 |

超出这些边界先回到批准和实验，不因“游戏化”默认加入后端、支付、广告、经营数值或上百种资源。
